# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report vulnerabilities privately through GitHub: go to this repository's **Security** tab and click **Report a vulnerability** (GitHub private security advisories). Include the extension version, VS Code version, and steps to reproduce.

You should receive a response within a few days. Fixes are released as a new extension version and noted in `CHANGELOG.md`.

## Supported versions

Only the latest published version of the extension receives security fixes.

## Note on stored credentials

Profiles, including passwords, are stored in plain text in your VS Code user `settings.json`. This is a known design limitation, not a vulnerability; see the README for details.
